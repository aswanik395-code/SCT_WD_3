# Grid Clash — Tic-Tac-Toe

A modern take on classic Tic-Tac-Toe. Challenge a friend or test your strategy against the computer.

🔗 **Live demo:** [aswanik395-code.github.io/SCT_WD_3](https://aswanik395-code.github.io/SCT_WD_3/)

## Features

- 👥 **Player vs Player** — two players, one device, take turns as X and O
- 🤖 **Player vs Computer** — choose your symbol and pick a difficulty: Easy, Medium, or Hard
- 🏆 Live scoreboard tracking wins for Player X, Player O, and draws
- 📜 Match history log
- 🔄 Reset game, change mode, or reset the full scoreboard anytime
- ❓ Built-in "How to Play" guide
- 🎨 Clean, responsive 3×3 grid UI

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)

## Usage

1. Choose a game mode: **Player vs Player** or **Player vs Computer**.
2. If playing the computer, pick your symbol (X or O) and a difficulty level.
3. Take turns placing X or O on the grid.
4. Get three matching symbols in a row, column, or diagonal to win.
5. If all nine cells fill up with no winner, it's a draw.
6. Use **Play Again** to start a new round, or **Reset Score** to clear the scoreboard.
